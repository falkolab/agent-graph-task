# Agent Graph Task

[English](README.md) · [Визуальное руководство (RU)](docs/guide.ru.html) · [English guide](docs/guide.en.html)

**Протокол организации задач для AI-агентов.** Текущая реализация — **Skill для Claude Code**, запускаемый вручную. Организует сложные задачи как граф ограниченных шагов с доказательной проверкой результатов, контролируемыми исправлениями, бюджетом ресурсов и продолжением работы между сессиями. Один протокол работает как при **прямом исполнении**, так и с **Dynamic Workflows**. Вызов Skill сам по себе не означает согласия на запуск параллельной работы: объём, число агентов и бюджет согласуются отдельно.

> **Статус:** v6.1. Проведено статическое ревью; реальные испытания в Claude Code, включая восстановление прерванных Dynamic Workflows, ещё не завершены.

## Установка

**В один проект** (выполняйте из корня проекта):

```bash
git clone https://github.com/falkolab/agent-graph-task.git /tmp/agent-graph-task
mkdir -p .claude/skills
cp -R /tmp/agent-graph-task/.claude/skills/graph-task .claude/skills/
```

**Глобально**, для использования из разных проектов:

```bash
git clone https://github.com/falkolab/agent-graph-task.git /tmp/agent-graph-task
mkdir -p ~/.claude/skills
cp -R /tmp/agent-graph-task/.claude/skills/graph-task ~/.claude/skills/
```

В Claude Code вызовите:

```text
/graph-task Проведи рефакторинг импортера без изменения внешнего поведения. Сначала предложи граф задач и критерии приёмки.
```

Перед разрешением выполнения проверьте план, область изменений и бюджет. Небольшие задачи Skill может выполнять напрямую; **Dynamic Workflows используются только при необходимости и после отдельного согласования**. Advisor — необязательный самостоятельный механизм, его не требуется устанавливать для работы Skill.

## Состав

| Файл | Назначение |
| --- | --- |
| [SKILL.md](.claude/skills/graph-task/SKILL.md) | Входная инструкция и обязательная загрузка протокола |
| [references/protocol.md](.claude/skills/graph-task/references/protocol.md) | Нормативные требования: выполнение, приёмка, бюджет, восстановление |
| [guide.ru.html](docs/guide.ru.html) | Визуальное руководство для человека, не нормативный документ |
| [guide.en.html](docs/guide.en.html) | Английское руководство |

`graph.md` описывает **согласованную спецификацию задачи**, а JavaScript Dynamic Workflow, когда он нужен, служит **механизмом исполнения**. `checks.md` содержит доказательства приёмки, `progress.md` — контрольные точки для продолжения работы. Эти файлы создаются **при выполнении задач**, а не входят в репозиторий в виде пустых шаблонов.
